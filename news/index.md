# Changelog

## gghockey 0.1.0

- First release: plotting functions pulled out of my private aRno
  package, which runs my hockey data pipeline. Includes
  [`annotate_rink()`](https://5plusspieldauer.github.io/gghockey/reference/annotate_rink.md),
  [`theme_rink()`](https://5plusspieldauer.github.io/gghockey/reference/theme_rink.md),
  IIHF / NHL dimensions and
  [`rink_dimensions()`](https://5plusspieldauer.github.io/gghockey/reference/rink_dimensions.md),
  [`rink_geometry()`](https://5plusspieldauer.github.io/gghockey/reference/rink_geometry.md),
  [`geom_rink_bin()`](https://5plusspieldauer.github.io/gghockey/reference/geom_rink_bin.md)
  /
  [`rink_bin()`](https://5plusspieldauer.github.io/gghockey/reference/rink_bin.md)
  with matching `scale_*_rink()` scales,
  [`team_palette()`](https://5plusspieldauer.github.io/gghockey/reference/team_palette.md)
  with team colour scales, and the simulated `shots` dataset.
