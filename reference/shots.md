# Simulated shots

A synthetic set of unblocked shot attempts between two fictional teams,
generated by `data-raw/shots.R` for examples and tests. Locations are
plausible but invented, and `xg` comes from a toy distance-and-angle
model, not a fitted one. All shots are taken towards the right-hand goal
(the high-`x` end) of an
[IIHF](https://5plusspieldauer.github.io/gghockey/reference/rink_dims.md)
rink, in metres with the origin at the bottom-left corner of the boards.

## Usage

``` r
shots
```

## Format

A data frame with 1,500 rows and 8 columns:

- shot_id:

  Shot id.

- game_id:

  Game id, 1-10.

- period:

  Period, 1-3.

- team:

  Shooting team, `"Lakeside"` or `"Northfield"`.

- x, y:

  Shot location, in metres.

- xg:

  Expected-goal probability from the toy model.

- goal:

  `1` if the shot was a goal, else `0`.
